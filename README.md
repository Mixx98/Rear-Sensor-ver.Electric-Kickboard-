# 🛴 전동킥보드 후방 감지 센서 (Rear Sensor ver. Electric Kickboard)

전동킥보드 뒤쪽에 다는 **후방 접근 감지 장치**입니다.
초음파 센서와 적외선 센서 6쌍으로 뒤에서 다가오는 물체의 거리를 4단계로 나눠 시리얼로 전송합니다.

## 주요 기능

- **초음파 센서 6개**로 후방 거리 측정
- 거리를 4단계로 분류

  | 값 | 단계 | 거리 |
  | --- | --- | --- |
  | `3` | VERY_NEAR | 0 ~ 30cm |
  | `2` | NEAR | 30 ~ 80cm |
  | `1` | FAR | 80 ~ 300cm |
  | `0` | VERY_FAR | 300cm 이상 |

- **적외선(광) 센서**가 감지하면 거리와 관계없이 `VERY_NEAR`로 처리
- 측정 결과를 `3 2 0 1 0 0` 같은 공백 구분 문자열로 115200bps 시리얼 출력 → 앱/디스플레이에서 경고 표시

## 핀 배치

- 초음파 Echo: D13 → D8, Trig: D7 → D2 (센서 순서대로 자동 할당)
- 적외선 센서: A0 → A5
